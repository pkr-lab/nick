# Dokumentation

Hier liegt die Dokumentation zu allen Experimenten auf Nicks Spielwiese. Der Code selbst enthält keine Kommentare – alle Erklärungen gehören hierher.

## Übersicht

| Experiment | Dokumentation |
|------------|---------------|
| –          | Noch keine Experimente vorhanden. |

## Vorlage für ein neues Experiment

Für jedes Experiment eine eigene Datei `docs/<experiment>.md` mit folgendem Aufbau anlegen:

```markdown
# <Name des Experiments>

## Ziel
Was soll ausprobiert oder gelernt werden?

## Technik
Verwendete Sprachen, Frameworks und Bibliotheken.

## Starten
Schritte, um das Experiment auszuführen.

## Aufbau
Welche Dateien gibt es und was macht jede davon?

## Erkenntnisse
Was hat funktioniert, was nicht, was wurde gelernt?
```
