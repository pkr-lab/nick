# Nicks Spielwiese 🌱

Willkommen auf Nicks Spielwiese – einem Ort zum Ausprobieren, Lernen und Experimentieren.

Hier landen kleine Projekte, Code-Schnipsel, Prototypen und Ideen, die einfach mal getestet werden wollen. Nichts hier muss perfekt, fertig oder produktionsreif sein.

Link zur besseren Übersicht des Repositorys:
<https://gitdiagram.com/pkr-lab/nick>

## Worum geht's?

- **Ausprobieren:** neue Sprachen, Frameworks, Bibliotheken und Werkzeuge testen
- **Lernen:** Konzepte verstehen, indem man sie selbst baut
- **Prototypen:** Ideen schnell umsetzen, bevor sie eventuell ein eigenes Projekt werden
- **Spaß haben:** Code schreiben, einfach weil es Spaß macht

## Grundregeln

1. Alles darf, nichts muss.
2. Jedes Experiment bekommt einen eigenen Ordner.
3. Was nicht mehr gebraucht wird, darf gelöscht werden.
4. Funktioniert etwas richtig gut, darf es in ein eigenes Repository umziehen.

## Aufbau

```
nick/
├── README.md          Diese Datei
├── docs/              Dokumentation zu den Experimenten
└── <experiment>/      Ein Ordner pro Experiment
```

Jedes Experiment liegt in einem eigenen Ordner mit einem sprechenden Namen, zum Beispiel `snake-spiel/` oder `wetter-api-test/`.

## Dokumentation

Der Code selbst bleibt frei von Kommentaren. Die Erklärungen dazu stehen unter [`docs/`](docs/README.md): Für jedes Experiment gibt es dort eine eigene Datei, die beschreibt, was es macht, wie man es startet und was dabei gelernt wurde.

## Loslegen

Repository klonen:

```bash
git clone https://github.com/pkr-lab/nick.git
```

Ein neues Experiment anlegen:

```bash
cd nick
mkdir mein-experiment
```

Danach unter `docs/` eine passende Datei `mein-experiment.md` anlegen und in der Übersicht in [`docs/README.md`](docs/README.md) eintragen.
